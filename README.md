# 📌 Project Overview

The **Car Price Prediction System** is an end-to-end Machine Learning application that predicts the resale value of used cars based on vehicle specifications such as manufacturing year, showroom price, kilometers driven, fuel type, transmission, seller type, and ownership history.

The project includes data preprocessing, model training, prediction, and deployment through an interactive Streamlit web application.

# 📊 Dataset

The dataset contains historical information about used cars, including:

- Manufacturing Year
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Previous Owners
- Selling Price

The data is preprocessed before training the machine learning model.
